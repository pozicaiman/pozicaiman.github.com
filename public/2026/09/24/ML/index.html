第 1 章 机器学习全景导论

1.1 什么是机器学习

机器学习（Machine Learning, ML）是让计算机从数据中自动归纳规律，并用规律对新数据做预测或决策的学科。它不用人显式编写规则，而是用算法自己去”学”。

形式上，几乎所有机器学习问题都可以写成一句话：

从样本集 $\{(x^{(i)}, y^{(i)})\}_{i=1}^{N}$ 中学习一个函数 $f: \mathcal{X} \to \mathcal{Y}$，使得它在新数据上的预测误差最小。

$x$ 是特征（如年龄、收入、点击次数），$y$ 是标签（如”是否购买”）。机器学习 = 假设空间 + 损失函数 + 优化算法——选择什么函数族（假设空间）、用什么度量误差（损失）、怎么搜索最优函数（优化），三者定了，一个 ML 问题就完全定义了。

1.2 三大范式

范式 数据形态 目标 典型任务
监督学习 有特征 + 有标签 学到 $x \to y$ 的映射 分类、回归
无监督学习 只有特征 发现数据内部结构 聚类、降维、异常检测
强化学习 状态/动作/奖励 学习策略使累计奖励最大 博弈、机器人控制

考虑到篇幅，本文主要覆盖监督与无监督。强化学习（策略梯度、Q-Learning）与深度学习结合更紧密，可另行成篇。

1.3 机器学习 / 深度学习 / 统计学的关系

  • 统计提供理论框架：估计、假设检验、偏差-方差。
  • 经典 ML 是”可解释 + 数据高效”的实用主义阵营：线性模型、树、SVM、KNN。
  • 深度学习 用多层非线性网络自动学特征，擅长图像/语音/文本，但需要大数据与算力。

关键分工（经典 ML 的不可替代处）：

  1. 表格数据（报表、交易、用户画像）：树集成模型（XGBoost/LightGBM/RandomForest）至今仍是基准最强。
  2. 数据量小：几千行样本时，经典算法比神经网络更稳。
  3. 可解释性要求高：风控、医疗、审计需要 SHAP、特征重要性，而非黑箱神经网络。
  4. 延迟敏感：毫秒级推理，核对了 CPU 就够。

2026 年的边界正在松动：表格基础模型（如 TabPFN）用海量合成数据预训练后可以”免训练”预测；LLM 驱动的 AutoML（如 LACE）能自动写出完整 pipeline。但这些系统的”终局模型”往往仍是 XGBoost/CatBoost——经典算法反而因此获得新生命力，详见第 7 章。

1.4 统一视角：经验风险最小化（ERM）

几乎全部监督学习都可以纳入同一框架。设损失函数 $L(\hat{y}, y)$ 度量预测与真相的差距，我们希望最小化期望风险（对未来所有数据的平均损失）：

$$ R(f) = \mathbb{E}_{(x, y) \sim P}\big[ L(f(x), y) \big] $$

但 $P$（真实数据分布）未知，只能近似为训练集上的经验风险：

$$ R_{emp}(f) = \frac{1}{N} \sum_{i=1}^{N} L\big( f(x^{(i)}), y^{(i)} \big) $$

于是学习问题变成：

$$ \boxed{\; f^* = \arg\min_{f \in \mathcal{H}} R_{emp}(f) \;} $$

不同算法只是”假设空间 $\mathcal{H}$ + 损失 $L$ + 优化器”的不同实例化：

模型 假设空间 损失 优化
线性回归 线性函数 均方误差 $\frac12\|y - Xw\|^2$ 解析解 / 梯度下降
逻辑回归 线性函数 + sigmoid 交叉熵 梯度下降
SVM 线性/核函数 合页损失 + 正则 对偶/坐标上升
决策树 分段常数函数 基尼/信息增益 贪心递归分裂
KNN 无显式参数 距离度量 无训练（懒惰学习）
